# P10B-16 — Coordinated Directions and Diversity Control

**Status:** Baseline
**Date:** 10 August 2026
**Provider calls:** zero

## Outcome

P10B-16 turns the bounded P10B-15 synthesis space into three governed coordinated constraint
packages: **Premium Editorial**, **Modern Technical**, and **Minimal Commerce**. They are not
templates, themes, page recipes, renderers, token stores, or executable output. Each package only
narrows current Design DNA, shared-frame, PageBlueprint profile, product-card anatomy, optional
page-family, narrative, merchandising, art-direction, density, and responsive authority.

The canonical lifecycle remains:

```text
approved merchant evidence + read-only canonical commerce
→ P10B-15 bounded synthesis authority
→ registered P10B-16 direction narrowing
→ current profile/frame/component/evidence validation
→ coordinated whole-storefront plan and proposal
→ canonical StorefrontSnapshot
→ save/reload and deterministic publication
```

No direction-specific renderer, template, registry, page graph, persistence representation, or
commerce model was added.

## Governed direction contract

The versioned `1.0.0` registry records an authority fingerprint over each package and validates all
profile, frame, product-card anatomy, Design DNA, optional page-family, narrative, density, art and
responsive references. A selection narrowing carries the exact package ID/version/fingerprint and
is revalidated before P10B-15 may use it. A repaired hash, stale reference, unsupported merchant
characteristic, incompatible frame/profile pair, unavailable asset posture, or impossible page
composition fails closed before proposal compilation.

Direction packages can omit only page families already marked optional by current site-map/evidence
authority. Home, search, contextual collection/PDP coverage, cart, checkout, no-results, empty,
error and 404 authority remain required. The bounded Design DNA finishing carried by the plan is
recomputed by the proposal compiler, so Modern Technical can use its registered standard/subtle
complete-store posture without reverting to a legacy fixed compact selection.

### Premium Editorial (`premium-editorial`)

- serif-led editorial Design DNA with balanced core spacing/surface compatibility and airy
  page-level rhythm;
- editorial/centered/commerce frame compatibility where the complete page set permits it;
- editorial, campaign and high-consideration homepage constraints;
- editorial/campaign discovery and high-consideration/gallery PDP constraints;
- curated/campaign/considered merchandising, editorial/immersive media and story-led pacing;
- optional story, service, campaign and legal page compositions only when approved facts exist.

### Modern Technical (`modern-technical`)

- sans-led, standard, subtle, product-led Design DNA with controlled information density;
- technical/commerce/centered frame compatibility where the page set permits it;
- commerce, collection-gateway, high-consideration and restrained homepage constraints;
- comparison/dense discovery and variant/standard/considered PDP constraints;
- discovery/dense/considered merchandising and contained/editorial media;
- no generated technical, specification, policy, guarantee, availability, or compliance claims.

### Minimal Commerce (`minimal-commerce`)

- restrained serif-led, balanced, subtle Design DNA;
- centered/commerce/editorial frame compatibility where the complete page set permits it;
- minimal, high-consideration and editorial homepage constraints;
- editorial/dense discovery and standard/considered PDP constraints;
- fewer stronger optional factual pages, restrained narrative and direct conversion continuity;
- complete required utility presentation, never an unfinished or generic shell.

## Direction and diversity fingerprints

Every selected store has a direction fingerprint covering current package authority, structural
Design DNA, frame, page profiles, meaningful component anatomies, art direction, density,
merchandising, narrative and responsive posture.

The independent diversity fingerprint contains machine-evaluable dimensions for:

- Design DNA structure, with palette isolated;
- page set and exact versioned PageBlueprint profiles;
- shared frame;
- meaningful component variants and canonical product-card anatomies;
- bounded parameter projection;
- art direction, density, narrative composition and responsive posture.

The comparator deterministically classifies `exact-duplicate`, `palette-only`,
`shallow-component-swap`, `near-duplicate`, or `materially-different`. Colour-only change never
changes the structural fingerprint. A material classification requires at least three changed
dimensions and at least one rendered architecture dimension. Direction names alone cannot create
diversity.

## Repetition avoidance and deterministic alternatives

For a fixed merchant authority, direction and seed, compatible candidates receive a deterministic
rank. Batch generation rejects exact, palette-only, shallow and near-duplicate candidates already
used in that batch and chooses a materially unused compatible combination. If no such combination
exists, it returns the typed `no-valid-diversity` error; it never broadens a package or forces an
invalid novelty.

The retained representative batch contains three complete outcomes per direction (nine total).
Across the batch, optional factual page composition, compatible homepage/collection/PDP profiles,
component anatomy, bounded Design DNA finishing, density, art and narrative postures vary while
required page/commerce authority remains intact. Pairwise outcomes within each direction classify
as materially different, and the three direction representatives are structurally distinct without
using palette.
