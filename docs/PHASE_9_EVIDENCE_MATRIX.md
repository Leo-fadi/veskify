## Evidence rules

One row records one claim. A merged implementation without the required test, browser, screenshot
or provider artifact is **Partial**, not complete. Empty evidence is written as **Not retained** or
**Not run**; it is never inferred from a document or a green unrelated test.

Required columns are requirement/AC, task, PR, commit, test, browser, screenshot, provider, status
and limitation. A future Phase 9 closing PR must replace every required Partial/Missing cell with a
safe retained artifact or an explicit approved exception.

## Phase 9 closing rule

Phase 9 closes only when the selected real-provider result:

1. produces a meaningful compatible shared frame, homepage, collection and dynamic PDP;
2. uses only live registered and compiler-preserved capabilities;
3. preserves canonical commerce and approved asset provenance;
4. passes proposal review, atomic accept, stale/invalid rejection and exact undo;
5. survives Save draft, reload, preview and explicit publish through the same
   `StorefrontSnapshot`;
6. passes EN/FI browser evidence at 375, 768, 1024 and 1440 px without leakage, clipping or
   inaccessible controls.

Token-only success, PR #123, mocked provider transport, deterministic fixtures or an API response
cannot satisfy this closing rule alone.
