# AR-05B approach

AR-05B adds an explicit, inactive composition-version boundary around the existing snapshot rather than a second storefront tree. The new structural codecs dispatch legacy and extension values without changing legacy readers. The binder resolves every owner from the parsed aggregate, delegates composition semantics to AR-05A, and produces only a deeply immutable accepted result.

A rejected shortcut was deriving layout from a retained commercial profile. Profiles prove compatibility and provenance only; AR-05A remains the layout authority. Legacy renderer, Puck, storage, history, proposal, and publishing paths remain strict and fail before producing a flattened legacy projection.

Current dynamic authorities can be structurally represented as v2 but cannot receive a positive composition until AR-06 provides executable commerce realization. This task preserves their specific current semantic failures.

The dynamic v2 codec preserves v1 material/refinements and composes it with an exact v2 fingerprint; it never manufactures v1 provenance. A resolver receives actual owner identity and cannot replace it. Current collection/search archetypes retain their single-family-context limitation, so structural representation is not a dynamic positive.
