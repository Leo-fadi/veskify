# AR-02M approach

AR-02M keeps the existing coordinated-direction metadata behavior and redirects four
current consumers to the defining schema, profile, eligibility, and design-system
modules. It does not create a second registry, schema, resolver, or execution path.

The retained-source reader receives four fixed AR-02M transitions. Each transition
binds the reviewed base, immutable historical hash, byte-exact archive, formatted
successor hash, and a caller-supplied historical pin. Invalid records, paths, pins,
archives, and successors remain fail-closed.

The rejected shortcut is forwarding through broad template, AI-generation, synthesis,
or design-system barrels. The expected failure behavior remains the existing strict
schema and compatibility errors with no partial output or input mutation.
