# Archived Veskify documentation exports

This directory retains superseded deterministic document exports as historical evidence.

`VESKIFY_SDD_v1.2.2.docx` records the v1.2.2 source baseline and must not be interpreted as current
implementation or phase status. Historical Phase 9 and P10A statements in that export remain valid
only for the baseline they recorded; they do not override later merged code, audits, evidence, or
documentation.

The active architecture authority is [`../VESKIFY_SDD.md`](../VESKIFY_SDD.md). Its synchronized
human-readable export is [`../VESKIFY_SDD_v1.3.0.docx`](../VESKIFY_SDD_v1.3.0.docx). Current task
status is maintained in [`../VESKIFY_DEVELOPMENT_DELIVERY_TRACKER.md`](../VESKIFY_DEVELOPMENT_DELIVERY_TRACKER.md)
and its synchronized
[`../VESKIFY_DEVELOPMENT_DELIVERY_TRACKER_v1.3.0.docx`](../VESKIFY_DEVELOPMENT_DELIVERY_TRACKER_v1.3.0.docx)
export.

Do not regenerate archived versions from current Markdown sources.

## Requirement-ID validation exclusion

The active consolidated requirement namespace is `FR-101` through `FR-124`, `NFR-101` through
`NFR-110`, and `AC-101` through `AC-138`. The v1.3.0 SDD preserves that complete inventory and is
the only authoritative definition site for those identifiers.

Pre-consolidation `FR-001`–`FR-099`, `NFR-001`–`NFR-099`, and `AC-001`–`AC-099` identifiers found
in historical phase/task reports are explicitly excluded from v1.3.0 definition validation. They
were task-local identifiers at their recorded baselines, are not aliases for the retained `101+`
namespace, and must not be cited as current v1.3.0 requirements.
